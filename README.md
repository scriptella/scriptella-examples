scriptella-examples
===================

Scriptella ETL usage examples

The examples target Scriptella 1.4 and Java 17. Maven examples use the
published `org.scriptella` coordinates. Database examples use H2 2.4.240;
HSQLDB is no longer supported by Scriptella 1.4.

The [SQLite → PostgreSQL example](sqlite-to-postgresql/README.md) targets
Scriptella 1.6 and Java 17, with external Xerial SQLite JDBC 3.53.4.0 and
pgJDBC 42.7.13. It includes independent source setup and destination verification.
